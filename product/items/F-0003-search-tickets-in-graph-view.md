## Proposed behaviour

In the graph view created by F-0005, the user can search for a ticket:

- Pressing `/` opens a search bar at the top of the view.
- As the user types, the input fuzzy-filters the tickets.
- The matching tickets are shown in a list above the graph.
- The user moves up through the matches with `n` and down with `shift+n`.
- No ticket is removed from the graph; the filter only affects the list of matches.
